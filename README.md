# Leaderboard Dashboard

A real-time leaderboard that polls a publicly shared OneDrive Excel file (via CSV URL) and auto-refreshes the UI.

## Current state

Project is scaffolded but not yet functional. No data fetching or UI components have been implemented.

## Prerequisites

- Node.js 18+
- A `.env` file based on `.env.example`

## Run

```bash
npm install
npm run dev   # → http://localhost:5173
```

## Build

```bash
npm run build
npm run preview
```
